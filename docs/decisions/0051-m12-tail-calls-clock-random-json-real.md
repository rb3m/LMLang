# ADR-051 M12: tail calls, clock/random, json, real-tokenizer S5, gobackend split (2026-10-17, agent consensus)

Process (ADR-030): Claude proposed; Codex and agy agreed and refined (refinements noted). Evidence: deep non-tail recursion made the old colsum binary worse than quadratic (ADR-050 item 7); the Lunar Lander (backlog 11) needs a clock, randomness and later JSON.
1. Tail calls. A call to the enclosing fn itself (by its own name; not a lambda, not mutual recursion) in tail position runs as a loop in the interpreter and the Go backend. Tail positions: the fn body; both branches of `if`; the body of `let`/`let?`; the last expression of `do`; every `match` arm body. Nothing inside a `try` form (body or handler) is a tail position (agy: one rule, simplest), nor anything in contracts or examples (Codex). New arguments are evaluated left to right into temporaries before any parameter is replaced (Codex). Self tail calls do not count toward E-RECURSION-LIMIT. Contracts are unchanged in meaning: `requires` is checked on every iteration; when contracts are on and the fn has `ensures`, each iteration's parameters are kept in a heap list and on exit every saved invocation's `ensures` is checked innermost first, clauses in written order, stopping at the first violation (Codex, agy), so a violation reports the same frame as before. Such fns use O(iterations) heap, not stack (documented). Go: the loop body binds the parameters to fresh per-iteration locals, so a closure created in one iteration never sees a later iteration's values (agy).
2. Clock: stdlib module `time`: `time.now-ms (sig -> Int) (eff time.now)` = Unix epoch milliseconds; `time.mono-ms (sig -> Int) (eff time.now)` = milliseconds from an arbitrary origin; only differences are meaningful (Codex).
3. Randomness: stdlib module `rand`, effect `rand`: `rand.int (lo Int) (hi Int) -> Int` inclusive, `(requires (<= lo hi))`, full Int64 span allowed (range computed as unsigned 64-bit `hi - lo`, never LM arithmetic); `rand.float (sig -> Float)` in [0, 1) = `(next() >> 11) * 2^-53`. Generator: SplitMix64 (agy), one 64-bit state per execution, state = seed as uint64 (two's complement of the Int64 seed); `next()` is the standard SplitMix64 step (add 0x9E3779B97F4A7C15, mix with 30/27/31 shifts and multipliers 0xBF58476D1CE4E5B9, 0x94D049BB133111EB). `rand.int`: span = hi - lo (uint64); if span = 2^64-1 return lo + next(); else n = span + 1, limit = 2^64 - (2^64 mod n), draw until x < limit, return lo + (x mod n) (wrapping uint64 then reinterpreted as Int64). Seeding: `lm run --seed N`, built binaries read env `LM_SEED`; absent = OS entropy; a malformed seed (not an Int64) is a usage error, exit 3, never silently entropy (Codex, agy). Runtime fixtures and differential tests run with a fixed seed reset before each case, so test order cannot matter (Codex). Examples on effectful fns stay rejected (no exception).
4. JSON: stdlib module `json`, exported sum `json.Json` = `JNull | (JBool (b Bool)) | (JInt (n Int)) | (JFloat (x Float)) | (JStr (s Str)) | (JArr (items (List Json))) | (JObj (fields (Map Str Json)))`; error `json.BadJson (pos Int) (msg Str)`. `json.parse (s Str) -> Json (fails BadJson)`: strict RFC 8259 grammar (one value, surrounding whitespace only); a number without `.`/`e`/`E` that fits Int64 is JInt, otherwise JFloat; a number not finite as binary64 is BadJson, never E-FLOAT; `-0`/`-0.0` normalise to `0`/`0.0` (Codex); duplicate object keys and unpaired surrogate escapes are BadJson; `pos` = zero-based code-point offset where the error was detected, identical in both backends; `msg` is one of a fixed set of messages listed in the SPEC (Codex). `json.print (j Json) -> Str` is pure and total (agy): compact, object keys ascending (Map order), Floats in the LM print rule, strings escape `"` `\\` and control characters (`\n \r \t \b \f`, others `\u00XX`), everything else literal UTF-8. `json.field (j Json) (key Str) -> (Opt Json)`: None for a non-object or a missing key, `(Some JNull)` for an explicit null (Codex). Parse and print are prims (Python and Go), `field` is LM. Object key order is not preserved.
5. Real tokenizer for S5: dev-only `bench/count_tokens.py` (stdlib `urllib`, `ANTHROPIC_API_KEY`, the Messages `count_tokens` endpoint); `lm bench --tokenizer anthropic` uses it and fails with a clear error if unavailable, never substituting the heuristic (Codex). Both languages use identical request framing (one user message containing only the source text); record model ID, API version, framing, source hashes and raw per-task counts. The heuristic numbers stay the default and are reported separately. S5 stays OPEN until a recorded measurement meets 1.3x.
6. Split `lm/gobackend.py` into `gobackend.py` (program, fn, contract, header) and `gobackend_expr.py` (the `x_*` emitters as a mixin), with shared helpers in neither importing the other cyclically; generated Go unchanged (byte-identical on the build fixtures).
