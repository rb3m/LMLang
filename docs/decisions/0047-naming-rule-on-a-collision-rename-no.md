# ADR-047 Naming rule: on a collision, rename; no exceptions (2026-10-17, owner guidance)

Owner: "the language is for LLMs so if there's a name conflicting with something else just pick another one ... as long as an LLM can keep track of it." Names carry no human-taste value in LM, while every exception is one more rule an LLM author must carry. So ADR-046 item 4 is reverted: `list.get` is renamed `list.at` (`(list.at xs i) -> (Opt a)`), and the stdlib-only permission to reuse a special-form name is removed; reserved words are reserved everywhere again. Rule for all future work: when a chosen name collides with a reserved word, prelude name, module or anything else, pick a different plain ASCII name (ASCII tokenizes better than symbols or emoji, which matters for S5) rather than adding a rule.
