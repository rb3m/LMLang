# ADR-046 M10 implemented: choices ADR-045 left open (2026-10-17)

Implements ADR-045 items 1-5 in every layer; no item changed. Decided by Claude under ADR-030's delegation.
1. Lexing: `?` is not a symbol character. The reader accepts exactly one extra word, `let?`, as a symbol; it is a special form and so reserved. Per-form dispatch maps `let?` to the method `*_let_q` (`prelude.form_method`). `(let? () body)` is allowed, as `(let () body)` is (the body must still be an Opt).
2. Checking: a binding expression is unified with `(Opt a)` (fresh `a`, bound to the name) and the body with `(Opt r)`; mismatches are E-TYPE at the binding/body node. Binding names go through the same no-shadowing check as `let`. Effects and failures of every binding count statically even though a `None` may skip them at run time (same as an `if` branch). `let` and `let?` share one binding walker in the checker and in lowering.
3. Lowering: innermost first, each binding becomes `Match(e, [Arm([tag Some], [(x, arg 0)], rest), Arm([], [], None)])`, so the Go backend needed no change; binding expressions keep their source paths (`.../1/k/1`), the body `.../2`.
4. `get` is a reserved word (record field access), so `list.get` could not be declared. Exception: a stdlib function may be named like a special form; it is only reachable qualified (`list.get`), and inside its own module the bare name stays the special form. User modules keep the old rule. Likewise `new` is reserved, so `str.replace`'s third parameter is named `replacement`.
5. Implementation split: `opt.*` and `str.pad-left/right` are LM bodies (pads over `str.repeat`), so both backends agree by construction even with `--no-contracts`; `list.get/take/drop/sort-by` and `str.index-of/replace/repeat/upper-ascii/lower-ascii` are prims (Python `prims.py`/`str_prims.py`, Go `prims.go`/`prims_text.go`). Without contracts `str.repeat` treats `n < 0` as 0 in both. `sort-by`: split at `len/2`, sort both halves, merge taking the right element only when `(less right left)` is true; Go and Python run these steps identically (fixture: an always-true `less`).
6. Fixtures: `tests/spec/check/letq-*` (types, payload, shadowing, scope, effects, failures, shape), `tests/spec/run/m10.lm` (one module, because a clean runtime fixture must run more than 25 examples: short-circuit past a failing and an overflowing binding, plus stdlib edge cases with Unicode and 64-bit counts), `tests/spec/build/letq-sort.lm` (a skipped binding prints nothing; sort-by in a binary), `tests/spec/fmt/letq`.
7. Measurement (item 5): EVIDENCE.md 2026-10-17. The ledger files were rewritten in a scratch copy and are not committed (ADR-044).
