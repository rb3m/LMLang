# ADR-036 `lm build` interface details; stdout buffering refines ADR-031 item 6 (2026-10-16, M8(c)/(d))

1. `lm build MOD.FN [PATH..] [-o OUT] [--os linux|darwin] [--arch amd64|arm64] [--no-contracts] [--keep-go DIR]`. PATHs are searched like `lm check`/`lm test` (so programs outside src/examples can be built). Default output `./MOD` when FN is `main`, else `./MOD-FN`. Binaries are static: `CGO_ENABLED=0`, `-trimpath`, `-ldflags=-s -w`, `GOTOOLCHAIN=local`, a generated `go.mod` declaring `go 1.21` (the oldest toolchain the runtime needs, for `min`). Size is about 2.5 MB.
2. Go discovery: `$LM_GO`, else `go` on PATH. Missing Go, an unknown flag/OS/arch, an unknown function, and an entry that breaks ADR-031 (parameters, or a result other than Unit/Int) are usage errors (exit 3); check errors exit 1; generated Go that fails to compile is a toolchain bug (exit 2, with the go output). An Int literal outside 64 bits is reported by lowering (exit 1) until M8(b)'s check-time E-OVERFLOW catches it earlier.
3. Stdout in binaries is line-buffered when it is a terminal and block-buffered otherwise; it is always flushed at exit and before a failure or fault is reported, and I/O prims that read stdin must flush it first (`out.Flush()`). This refines ADR-031 item 6 ("line-buffered"): flushing every line into a pipe costs a system call per line with no observable benefit once reads flush first.
4. Faults print the same JSON diagnostic shape as the toolchain (code, severity, file, line, col, path, msg, expected, found, fix) on stderr. E-EXIT-RANGE is binary-only (`lm run` prints the result instead).
5. Tests (M8(d)). `tests/unit/test_gobackend.py` compiles every example of stdlib, examples, tests/spec/run and bench/tasks into one harness binary (`gobackend.emit_cases`, `rt.go runCases`) and requires outcomes identical to the interpreter's (`runner.example_outcomes`): value text for successes, `(fail ..)` text for failures, the code for faults. Built-binary fixtures live in `tests/spec/build/NAME.lm` (entry `main`) + `NAME.expect`, a JSON list of runs `{flags?, exit, stdout, stderr?, code?, interp?}`; each run is also executed by the interpreter and must agree unless `"interp": false` (overflow until M8(b), exit range, depth beyond the interpreter). Without Go these tests skip and print `SKIP: Go toolchain not found` on stderr; they never pass silently.
Revisit: if owners want `--allow`-style narrowing in binaries, or a Windows target.
