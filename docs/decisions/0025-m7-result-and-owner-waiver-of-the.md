# ADR-025 M7 result and owner waiver of the S5 trigger (2026-10-15)

Added `list.all`, `list.any`, `list.map2`, `list.index-of` (prims in lm/prims.py) and rewrote the three bulkiest tasks to use them (dot, search, primes; edits done with `lm edit`, and the unused-`fails` warning W-FAILS-UNUSED pointed at the leftover declarations). Re-run of the unchanged suite: S5 1.37x -> 1.34x (dot 2.05x -> 1.44x, search 1.60x -> 1.22x); S3 43/43, S4 13/13, S6 6/6. Three S3 mutations had to be retargeted because their anchor text disappeared from the rewritten files (marked in lm/bench.py); same categories, same count. Not done: a sequencing form for effects (greet 2.64x) and table-driven roman (2.34x), which remain the two outliers.
S5 is still above 1.3x, so by the pre-registered rule (ADR-024) the ADR-011 fallback would trigger. The owner explicitly waived this: "Don't fret too much over the size vs Python. We can refine later." Decision: continue LM, S5 stays an OPEN metric (not passed), to be revisited with the two outlier fixes and a real tokenizer. The fallback remains available and the tooling is language-agnostic enough to extract. The benchmark numbers are not to be reported as "gate passed" anywhere.
