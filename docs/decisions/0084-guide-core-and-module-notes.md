# ADR-084 Backlog 32: a fixed core guide plus per-module notes (2026-11-25, agent consensus)

Status: accepted (2026-11-25). Owner request: the guide grows with every library; keep each library's description in the library, or move libraries out of the core.

Context: `lm guide` was 7,009 bytes at creation (2026-10-19), 9,200 the same day, and has sat at its 9 KiB test cap for a month: each module adds a line and older lines get compressed to fit. About 2.6 KB are per-library lines and 1.4 KB more list module members. Every module already has a one-line `purpose`; `lm index --stdlib --modules` lists them (1.3 KB) and `--module M` prints every signature with effects, failures and fn purposes (http: 1.3 KB). What has no home outside the guide: module caveats signatures do not show (HTTP plaintext only to loopback; proc needs an absolute argv[0]; pat is leftmost-first; date years 1..9999).

Options: (1) bigger cap; (2) topic sections (`lm guide http`); (3) a core guide plus caveats carried by each module; (4) move libraries out of the core (to `ext/` or pinned externals).

Decision (Claude, Codex, agy unless noted):
1. (3). The guide keeps only what every program needs: workflow (including "run `lm index --stdlib --modules`, then `--module M` before using a module"), module/fn/type/const/generic skeleton, expressions and literal forms (`vecof mapof setof bytesof` syntax only), prelude names, core type rules (Map/Set keys, List-only `len`/`for`, Pair), naming and Int/Float rules, the effect vocabulary, one `given` example, scenario format and approval, a short dependency trust rule. Library member lists and library caveats move out. Hard cap 6 KiB (6,144 bytes), enforced by the existing test. A bigger cap taxes every cold start with libraries it does not use; topic sections duplicate `index --module` and split maintenance.
2. Module clause `(notes "...")`: optional, one line, at most 500 UTF-8 bytes, at most once (E-NOTES otherwise). Printed directly under the module header by `lm index --module M`, for every origin; not in `--modules`, `slice` or `explain`, which stay compact. Notes from third-party modules are printed marked as untrusted data, like other external text. Every stdlib and ext module with a constraint its signatures and purposes do not show gets notes (checked by a unit test listing them). Fn-specific bounds go in that fn's purpose when they fit.
3. No module moves out of the core now (Codex, agy; Claude had proposed `date`): once its caveats leave the guide a stdlib module costs about 65 bytes in `--modules`, while an opt-in costs a `lm.deps` edit and a discovery step. `ext/` stays for OS- or hardware-bound modules like `hid`. Revisit with usage evidence.
4. Discovery (Claude, agy; Codex preferred a separate `lm index --available` catalog): `lm index --stdlib --modules` also lists available `ext/` modules, marked `opt-in: (ext STEM) in lm.deps`, and `lm index --module M` resolves stdlib, ext (declared or not, marked) and declared pinned modules, so an agent never has to guess a flag.
5. Proof: rerun the ADR-065 cold start before and after on three tasks fixed in advance: (T1) the ADR-065 word-frequency CLI (core only); (T2) a caveat-heavy `proc` + `fs` CLI with `given proc` examples; (T3) an `ext/` task decoding mouse reports from a supplied `LM_HID_REPLAY` trace. Fresh agents in empty directories outside the repo, PATH with only `lm` and the runtimes, two model families (Codex and Claude). Measure documentation bytes read, index calls, check/test cycles, completion against hidden checks, and caveat misses. Target: at least 20% lower median documentation bytes with no completion or caveat regression.

Revisit when: the guide nears its cap again, agents skip `--module M` and guess APIs (caveat misses), or a module is rarely used (then move it to `ext/`).

Result (2026-11-25, v0.15.0): implemented by Codex (gpt-6.2-sol, medium), verified by Claude. Guide 9,216 -> 6,134 bytes; all 20 stdlib modules and ext/hid carry notes. Cold starts (docs/EVIDENCE.md, 12 runs, one per task, agent and condition): median documentation read -16.6%, short of the 20% target, because agents read more `index --module` output; every run passed its hidden checks in both conditions; session cost fell 27% (Claude) and 12% (Codex). The after runs found four documentation gaps, fixed the same day, and two language gaps, queued as backlog 33-34. Next lever if the target matters: a narrower lookup than a whole module (e.g. one fn's signature plus its module's notes).
