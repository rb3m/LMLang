# ADR-027 ADR-026 accepted; server target facts (2026-10-16)

The owner approved ADR-026 as written (Go backend, shared lowering IR, 64-bit Int with `Overflow`, interpreter as oracle); M8 is now scheduled. The owner checked the DreamHost plan: Python 3.12, PHP 8.2 (the owner may be able to upgrade it), Linux on x86_64.
Consequences. (1) The reference interpreter needs only Python >= 3.10 and stdlib, so copying the repo and running `python3 -m lm run ...` should work on the server today with no new code (slow, but zero work; not yet tried). (2) `lm build --os linux --arch amd64` is the matching native target; whether shared hosting lets the binary run (and for how long) is tested during M8(e), not assumed. (3) The first server backend after M8 is Python (Python 3.12 has unbounded ints and floor `//`/`%`, so the ADR-026 Int bound becomes an explicit check); PHP is not planned unless the Python path fails, because it needs floor-division helpers and its version may change.
