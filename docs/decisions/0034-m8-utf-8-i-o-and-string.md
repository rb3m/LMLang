# ADR-034 M8(a) UTF-8 I/O and string parsing details (2026-10-16)

ADR-031 leaves error names and parsing boundaries open. File operations declare exported `fs.IoError (path Str) (msg Str)`; stdin reads declare exported `io.IoError (msg Str)`. OS and decoding errors become these failures, with host error messages (not portable text). `fs.exists` follows symlinks, returns false for missing targets, and fails on other stat errors. Writes replace/create a file, preserve text exactly, and are not atomic; reads preserve newline text. Print/eprint retain the `io.out` contract and flush each line. The runner consumes stdin bytes as strict UTF-8 regardless of locale; `read-line` removes LF and its optional preceding CR, distinguishes empty lines from EOF, and accepts a final unterminated line.
`str.split` takes separator first, like `join`; literal splitting preserves empty fields, and an empty separator returns Unicode characters (empty input gives an empty list). `trim` removes Unicode whitespace. `starts-with` and `contains` take the subject first. `substring` uses zero-based Unicode character offsets, start inclusive/end exclusive; invalid bounds fail prelude `OutOfRange`, including reversed bounds. `lines` recognizes CRLF, LF, and CR only; empty input gives no lines, interior empty lines stay, and the final terminator adds no empty line. `to-int` accepts only optional ASCII +/- followed by one or more ASCII digits, without whitespace or separators; leading zeroes are allowed. Invalid syntax or values outside signed 64-bit bounds fail exported `str.ParseError (text Str)`, including arbitrarily long input, independently of arithmetic overflow work.
The function runner preserves its printed result and success status 0, including Int results (ADR-031 item 2). All runtime diagnostics, including denied effects, go to stderr and exit 70; static diagnostics retain exit 1 and their existing stream. No approved acceptance scenarios change.
Merge note (2026-10-16, Claude): ADR-032 and ADR-034 disagreed on E-EFFECT-DENIED under `lm run`. Resolved: every runtime diagnostic goes to stderr after flushing stdout (ADR-034), faults exit 70, and E-EFFECT-DENIED exits 1, because it reports a missing `--allow` on the runner, not a program bug, and cannot occur in a binary (ADR-031 item 4).
