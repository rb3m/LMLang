# ADR-045 M10: `let?` short-circuit binding and a stdlib batch (2026-10-16, agent consensus)

Process (ADR-030): Claude proposed from the ADR-044 evidence; agy (the outside author who hit the problem) and Codex agreed with refinements, merged here.
1. `(let? ((x e1) (y e2) ..) body)`: each `ei` has type `(Opt Ti)` and binds `x` to the payload; bindings are sequential (later ones see earlier names), each evaluated exactly once, left to right; the first `None` skips the remaining bindings and the body and makes the form `None`. `body` has type `(Opt R)` and so does the form (explicit `Some` keeps the Opt visible). No shadowing (ADR-016); effects, failures and faults flow as in `let`. Lowered to nested matches in every backend, keeping source node paths for diagnostics.
2. `opt` module: `unwrap-or (o (Opt a)) (d a) -> a` (the default is evaluated eagerly, like every argument), `map`, `is-some`. No `and-then` until an experiment asks for it.
3. `list`: `get (xs) (i) -> (Opt a)` (None out of range; the Opt twin of `nth`), `take`/`drop` (counts clamp: negative acts as 0, beyond the length as the length), `sort-by (xs) (less (Fn (a a) Bool))`: stable; `less` should be a strict weak ordering, and both backends run the same top-down merge sort so even an inconsistent `less` gives identical results. No `zip` (`list.map2` builds pairs).
4. `str` (indices and widths count Unicode code points): `pad-left`/`pad-right (s) (width) (fill)` with `(requires (= (str.length fill) 1))`, returning `s` unchanged when it is already at least `width` long (no promise about terminal display width); `repeat (s) (n)` with `(requires (>= n 0))`; `index-of (s) (part) -> (Opt Int)` (first match; empty `part` is `Some 0`); `replace (s) (old) (new)` (all non-overlapping occurrences, left to right; empty `old` returns `s` unchanged); `upper-ascii`/`lower-ascii` (only `a-z`/`A-Z` change; Unicode casing deferred until its semantics can be pinned across backends).
