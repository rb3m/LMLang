# ADR-023 Acceptance oracle: hash-locked scenarios, status excluded from the digest (M5)

Scenarios are domain-language cases the human approves; the lock stores digests of approved ones. Excluding `status` from the digest lets approval be a one-word edit while any change to meaning is detected. An approved scenario absent from the lock is a guard failure, so an agent that self-approves is caught by `accept --guard` (mandatory before "done"). `--bless` requires an interactive TTY. Scenario runs reuse the checker for arguments and expectations (a mistyped scenario is reported, never crashes) and the interpreter with contracts on and only the scenario's declared effects allowed. Decision: proposed scenarios deliberately include questionable behaviors (VAT rounds down, pi = 3) so the human reviews real judgment calls, not only tautologies.
